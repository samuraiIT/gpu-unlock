# Изменения v0.2.0-20261029

- main.c, recipes.c/h: изолированное экспериментальное сопоставление 2820/sub1558:0157/a1,
  отдельный opt-in, точное сопоставление PCI-адреса, сохранение выбора остальных ID.
- unlock_610.c: запрет resume для мобильного кандидата до начала доступа к устройству.
- tools/windows_probe.py: read-only NVAPI, системный путь DLL, явные ошибки,
  отсутствие GPU считается ошибкой; запись JSON только в новый файл.
- tests: реальные функции выбора рецептов, wildcard/partial-address отказы,
  PCI revision и NVAPI lifecycle/error mocks.
- Документация: разделены сборка, идентификация, экспериментальный Linux путь и
  ещё не реализованный Windows unlock; сохранены backup и инструкции отката.
- windows/rtx4070-laptop-probe: MIT diagnostic с pinned EDK2 headers, без GPU MMIO,
  physical PROM и unlock; MSVC host mocks и PE checks. Вендорские заголовки (~0.9 MB)
  нужны для ABI UEFI; библиотек или runtime-пакетов не устанавливают. Альтернатива —
  полный EDK2 checkout; удаление этого каталога удаляет Windows probe целиком.

Владельцу доступны исходники и сборочные результаты. Системная установка и
аппаратное включение экспериментального пути не выполнялись.
