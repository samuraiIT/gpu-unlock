# Откат

## Выполненная работа

Установленного Windows unlock нет. EFI, BCD, Secure Boot, драйвер и VBIOS не
изменялись инструментами этой работы; откатывать ОС после разработки не требуется.
Чтение BitLocker/BCD не удалось без повышенных прав, поэтому их полный backup
и побайтовая проверка неизменности не заявляются.

Исходники до правок сохранены локально в
`backups/v0.2.0-20261029/files-before/` с SHA-256 manifest. Backup не публикуется.
Это резервная копия исходников, не образ диска/EFI и не recovery key.

Для отмены опубликованной разработки используйте `git revert <task-commit>` в
отдельной ветке либо перейдите на сохранённую baseline-ветку после сохранения своих
локальных изменений. Не используйте reset/force-push для существующего main форка.
Новые результаты диагностики можно архивировать отдельно; они не установлены в систему.

## Будущие аппаратные опыты

До первого запуска нужен отдельно проверенный штатный загрузочный путь, доступ к
BitLocker recovery (если включён), сохранение существующих USB-файлов и возможность
полного выключения. Предзагрузочный probe собран, но не установлен на USB.
Не переименовывайте и не заменяйте внутренний Windows Boot Manager.

Возврат к обычной загрузке после будущего эксперимента и восстановление Secure Boot
должны быть испытаны на этой машине. Опыт других плат не является доказанным откатом
для неё. Текущий исходный Linux-кандидат для повторного unlock после сна не допускается.
