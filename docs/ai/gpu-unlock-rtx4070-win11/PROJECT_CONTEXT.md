# GPU unlock для RTX 4070 Laptop

Цель владельца: безопасная разблокировка на Windows 11 с возможностью отката.
Версия разработки: v0.2.0-20261029. Статус: исследование, Windows unlock не реализован.

Устройство: NVIDIA 10de:2820, subsystem vendor 1558, subsystem device 0157,
revision a1; NVAPI architecture 0x190, implementation 6. Данные получены с реального
устройства через официальный драйвер. Они не доказывают совместимость firmware.

Архитектура: существующий Linux AD10x transaction остаётся неизменным, добавляется
ограниченный выбор конкретной платы и запрет resume. Windows user-mode инструмент
работает только через query API. Будущий preboot backend должен быть отдельным и
проверяться по фактическим данным UEFI этой платы.

Критерий окончания исходной задачи — повторяемый прирост после запуска штатного
Windows-драйвера, корректные численные результаты и испытанный штатный возврат.
Этот критерий пока не достигнут. Сборка и unit-тесты закрывают только программный этап.

Нельзя расширять аппаратные ограничения ради успешного запуска, включать кандидат
через targets=all или выдавать совпадение модели за проверку Windows-порта.
Серийные номера, ключи, raw ROM, loaded driver images и личные пути остаются локальными.
