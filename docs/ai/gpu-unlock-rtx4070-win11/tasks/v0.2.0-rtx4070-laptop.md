# Task receipt — v0.2.0-20261029

Запрос: форк Zagitta/gpu-unlock и поддержка RTX4070 Laptop в Windows11, с безопасным откатом.
Форк samuraiIT/gpu-unlock существовал при проверке; чужие изменения main сохранены.
Разработка изолирована в research/rtx4070-laptop-2820-windows на upstream 7eb51bcc.

Получены: точная идентификация платы, экспериментальный ограниченный Linux путь,
Windows NVAPI diagnostics, тесты и сборка модуля. Выполнено независимое review;
исправлен пропуск PCI revision в Windows profile match и расширены error-path tests.

Не получены: проверенный Windows unlock backend, предзагрузочный capture этой
машины, эффект после штатного драйвера, cold A/B/A и аппаратно испытанный откат.
Не считать эту ветку завершением аппаратной задачи или готовым Windows установщиком.

Следующий необходимый материал: приватная UEFI-диагностика именно этой платы.
Для безопасного аппаратного этапа требуется участие владельца у ноутбука и отдельный
цикл проверки восстановления; во время текущей сессии загрузка ОС не прерывалась.
